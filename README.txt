# SASOL INDUSTRY — projeto Android inicial

Este é um protótipo Android offline com login demonstrativo, menu, equipamentos, diagnóstico manual e configuração de limites.

## Gerar APK usando apenas o telemóvel
1. Crie uma conta no GitHub e inicie sessão no navegador.
2. Crie um repositório novo chamado `sasol-industry`.
3. Envie todos os ficheiros e pastas deste ZIP para o repositório (mantenha a estrutura).
4. Abra o separador **Actions** e selecione **Build SASOL INDUSTRY APK**.
5. Toque em **Run workflow**. Quando terminar, abra a execução e descarregue o artefacto `SASOL-INDUSTRY-APK`.
6. Extraia o ZIP do artefacto e instale `app-debug.apk` no Android. Poderá ser necessário autorizar a instalação de aplicações desta origem.

## Acesso demonstrativo
Palavra-passe inicial: `201300`. Altere-a antes de qualquer demonstração pública.

## Aviso de segurança
Este protótipo recebe valores manualmente. Não está ligado a sensores nem constitui um sistema de segurança industrial certificado. Os limites de 300 °C, 100 bar e 10 %LEL são os valores iniciais do código fornecido e devem ser validados por profissionais qualificados antes de qualquer uso operacional. Nunca use o protótipo para comandar ou substituir sistemas reais de proteção.
